# 网络诊断：路径拓扑与节点互测

在“网络诊断”下打开“路径拓扑”或“节点互测”。二者测试服务器的直接网络；Reality/HY2 代理握手和完整中转业务链路继续使用“节点一键诊断”。

## 路径拓扑

选择落地 IP 或域名，并勾选候选中转 Agent。不同来源独立逐跳探测，可比较 IP、延迟、ASN、运营商和近似地区。支持 ICMP/TCP/UDP、指定端口、IPv4/IPv6。升级 Agent 后可点击“准备 NextTrace”，仅按明确请求下载安装 SHA256 固定的官方 v1.7.4。缺少 NextTrace 时保留 traceroute/tracepath 基础结果；不支持的选项明确报错。

地区/ASN 查询使用 NextTrace 的数据服务，可能向服务方查询跳点 IP；地图为面板本地拓扑，不创建公开分享地图。地区信息是推测，不能等同物理光缆位置。单跳不回应不代表业务丢包。反向路径需要从落地 Agent 独立追踪。

## 节点互测

两端均须为已接入的 Agent。选择同一个落地和最多八台候选中转，按相同 IP、协议、连接数与时长依次测试。默认 TCP、IPv4、每方向10秒、单连接、100 Mbps 总速率，先中转到落地，再反向测试；可改为同时双向或 UDP。

默认测试端口5201，可选择1024–65535的其他空闲端口。落地需允许所选 TCP 端口；UDP 测试还需要同端口 UDP。程序不会重写防火墙。临时监听使用每项独立随机账号/密码和 RSA OAEP 认证，任务结束、取消或租约到期后关闭；Linux Agent 退出也会杀掉测试子进程。取消后的端点最多等待15秒清理后再复用。

iperf3 最低3.22，拒绝存在旧认证问题的版本和弱填充降级。点击“准备测速工具”会校验官方固定源代码 SHA256，在具备 cc、make、tar 和 OpenSSL 开发文件的 Linux 主机上构建独立程序到 /usr/local/lib/subl/iperf3；缺少依赖时显示具体错误，可预先提供满足版本的程序。现有系统 iperf3 服务不会被替换。

速率上限按所有并行连接的总和计算；同时双向时两个方向平分总上限。预计数据量为速率×时长×方向批次×来源数，不含协议开销和账单的双端计费。有限速测试达到上限时，只能说明该速率可用，不能据此推断最大容量。

最终数字与曲线采用接收端结果；实时发送端观察单独标识。TCP 展示重传及可用时的平均 RTT；UDP 展示接收速率、丢包和抖动。CPU 是 iperf3 进程占用。历史保留七天；任务凭据不会出现在管理 API 和历史中。

参考：[NextTrace](https://github.com/nxtrace/NTrace-core)、[iperf3](https://software.es.net/iperf/invoking.html)。
