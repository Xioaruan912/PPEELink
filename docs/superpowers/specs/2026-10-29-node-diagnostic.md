# Node diagnostic
User requests a dedicated page under subscriptions/nodes, covering Reality and HY2 including XHTTP. Run from panel network and state perspective. Accept stored node or pasted URI. Isolated Xray client with pinned public server address, random authenticated local SOCKS, bounded concurrency/deadline/output and cleanup. Stages: configuration, DNS, transport (TCP only for Reality, HY2 marked unconfirmed pending QUIC), core selfcheck, real tunnel HTTP, destination HTTPS. Do not claim TCP reachability proves handshake/auth. On ambiguous timeout list possible causes rather than invent certainty. Fixed external targets only, refuse nonpublic server destinations and unsafe transport extra redirects, no credential or raw log output. Existing settings and traffic unchanged. Supported Reality RAW/XHTTP/WS/gRPC/HTTPUpgrade; HY2 TLS/pin/salamander. Unsupported parameters explicitly fail locally rather than silently discarded. Tests core configs, errors/secrets, real success and failure; frontend mobile, admin endpoint; deploy.
