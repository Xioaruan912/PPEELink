# Batch node diagnostic and source switch overflow
User requests testing all nodes in one click and removing the source-switch horizontal scrollbar. Browser-side bounded queue uses existing isolated /nodes/diagnose endpoint. Two workers max, stable target and node snapshot, per-row results/errors, cancellation aborts active requests and marks unstarted nodes cancelled. Existing completed results survive cancellation. Unsupported protocols are explicitly skipped, not reported as network failures. Clicking a row shows the existing detailed diagnostic report. No credentials copied into results.
Source switch overflow came from animated absolutely-positioned slider contributing scroll extent inside overflow-x:auto. Clip the decorative layer within an absolute track, retain horizontal navigation for genuine many-option components. The two-option diagnostic source selector uses two equal shrinkable columns with no horizontal scroll. Desktop and 380px browser tests verified batch pass/fail/unsupported totals, clickable details, no page overflow and switch scrollWidth==clientWidth. Queue tests cover bounded concurrency, errors and cancellation; frontend typecheck passed.
