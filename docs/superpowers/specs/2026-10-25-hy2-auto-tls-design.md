# Domainless HY2 deployment
User approved automatic self-signed certificates with authenticated subscription delivery. Agent generates ECDSA certificate/key locally, persists a private atomic bundle, and reports only the public certificate after successful apply. Each activation has a random TLS identity; stale reports cannot replace a new identity. Panel binds first valid certificate, refuses silent replacement and excludes pending listeners from subscriptions. Fixed SAN hy2.subl.invalid requires no DNS resolution; connection address is server IP. Existing manual certificate mode remains supported. Certificates persist across restarts, five-year validity, no automatic identity rotation.
Mihomo uses certificate fingerprint; official HY2 URI carries pinSHA256. sing-box full output embeds the validated public certificate with insecure=false. Unsupported converters omit pinned nodes rather than discard authentication. Private keys never leave Agent. Unknown/old Agent capability rejects automatic mode. No automatic production listener added to an unspecified server.
