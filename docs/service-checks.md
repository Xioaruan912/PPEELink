# 服务可用性检测

在“网络测试”中使用“指定节点”或“当前设备”。

- **指定节点**：由面板通过所选节点发起请求，用于比较节点出口的服务可用性。可选全部常用服务、AI、影视、地区电视、社交及其它类别；节点列表中的解锁弹窗使用相同检测逻辑。
- **当前设备**：由浏览器直接请求目标服务，跟随 Clash Verge 等客户端实际代理和分流配置。使用前启用需要测试的代理。结果只在当前页面内保留，不写入节点历史；切换到指定节点不会混用结果。

首批共18项：OpenAI / ChatGPT、Claude、Gemini、Copilot、Grok、Perplexity、Le Chat、Poe、Netflix、YouTube、Disney+、DAZN、Crunchyroll、TVB Anywhere+、Google、GitHub、Telegram、TikTok。

## 结果含义

| 显示 | 依据 |
| --- | --- |
| 接口通过 / 明确受限 | 地区接口返回明确字段或明确的地区拒绝 |
| 页面可用 | 页面包含已知可用标记；没有验证账号或实际功能 |
| 推测可用 / 推测受限 | 该目标服务返回的地区与地区规则比较；不会使用其它服务的国家代替 |
| 仅可访问 | 只能证明连接或首页可达，不能证明登录、播放或生成功能 |
| 无法判断 | 超时、连接失败、验证页面、未知响应或浏览器限制 |

Netflix 的地区跳转不能证明完整片库可播放；浏览器不运行上游的跳转计数链，因此通常仅报告首页可达。Claude 等 trace 探针只提供该服务看到的地区，不代表已经通过风控。浏览器的 CORS 限制下，opaque 响应的 HTTP 状态不可读取，只能报告连接可达性。

每次最多同时检测4项，每项最多8秒，整轮最多45秒。结果逐项显示，可随时停止；离开页面或切换入口时取消请求。中止、超时或断流后的部分结果不会作为完整结果缓存。完整节点检测缓存60秒；分类与单项检测各自隔离。旧版缺少依据的浏览器存储结果需要重新检测。

地区规则和部分探针来自 `yt1988/unlock-check` 的 `e941ebde9413ee844ecd34e8ea4ed8ccf7ac0a43` 快照。端点及地区政策变化后需要维护；许可见仓库根目录 `THIRD_PARTY_NOTICES.md`。本次不增加 Agent 依赖，也不强制选择 IPv4 或 IPv6。
